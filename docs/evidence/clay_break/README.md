# Clay-break evidence investigation

**Status:** DISCOVERY / EVIDENCE ONLY  
**Recovery date:** 2026-10-03  
**Implementation authority:** NONE

This directory records a bounded recovery investigation into what happens when shotgun pellets contact clay targets and how physical damage relates to competition scoring.

## Epistemic boundary

These distinctions are mandatory:

- **GEOMETRIC_CONTACT ≠ DAMAGE**
- **DAMAGE ≠ SCORING DAMAGE**
- **PENETRATION ≠ SCORING DAMAGE**
- **SCORING DAMAGE ≠ CATASTROPHIC BREAKAGE**

Finding a source or an empirical association does not validate a BangLab break model. Nothing in this directory changes the current model, fixtures, build contract, claims, gate definitions, or E0–E8 state.

## Current finding

Direct evidence establishes that pellet contact does not deterministically imply a scoring-visible break. Recovered targets have shown pellet holes/marks without a qualifying visible fragment, including conventional pitch targets with multiple pellet marks. The evidence therefore falsifies a simple CONTACT → BREAK rule, but does **not** provide a sufficiently complete universal calibration for break probability.

The highest-information-value unresolved object is the raw laboratory dataset underlying James Anthony Pautler's *Analysis of Skeet Target Breakage* patent family.
