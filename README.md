# BangLab

Evidence-bounded clay/shot modelling experiments.

## Current scope
v0.1 is a deterministic Eulerian encounter/intensity-field experiment for geometric pellet contact with a declared clay silhouette using the DEP 99/953 reference load over 20–50 m.

It is **not** a breakage/scoring predictor, personal-cartridge model, DTL trajectory model, DEM/CFD simulator, or validated 3-D shot string.

## Status
See `STATE.md`. Production implementation is currently blocked pending recovery of the raw DEP p.82 per-round fixture required by E1.
